# 基于 Transformer 的情感分析
本项目基于PyTorch原生`nn.TransformerEncoder`从零搭建文本分类流水线，在IMDB电影评论数据集上开展情感二分类实验，核心目的在于通过控制变量法探究词嵌入维度对语义表征能力的影响；模型严格遵循Transformer编码器标准架构，先将离散Token映射为稠密向量并与正弦余弦位置编码叠加以注入序列顺序信息，再经由堆叠的多层多头自注意力机制捕获全局双向语义依赖，最终提取序列首位置的聚合向量作为整句表征；为排除分类器差异对评估结果的干扰，实验设计采用“辅助分类头监督训练Encoder，冻结后转用逻辑回归进行线性探测”的两阶段策略，客观对比100维与200维句向量在语义空间中的线性可分性，从而深化对Transformer内部注意力机制、位置编码及特征提取流程的理解。
